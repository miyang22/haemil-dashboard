# 해밀 영업지도 (해밀홈케어 영업용 지도 PWA)

워킨맵(Work in Map) 스타일의 **방문 영업용 지도 앱**입니다. 노원구 학원·교습소 1,412곳을
지도에 띄우고, 방문할 때마다 영업상태와 메모를 남기고, 그 결과를 구글 시트에 그대로 저장합니다.

- 주소: **https://miyang22.github.io/haemil-dashboard/sales-map/**
- 홈 화면에 추가하면 앱처럼 열립니다(PWA).

## 이 저장소에 학원 명단이 없는 이유

`miyang22/haemil-dashboard`는 **공개 저장소**입니다. 전화번호·주소가 들어 있는 영업DB는
파일로 올리지 않고, 다음 두 가지 방법으로 **각 기기 브라우저(localStorage)에만** 저장합니다.

1. **구글 시트 실시간 연동** — Apps Script 웹 앱(JSONP)으로 읽고 씁니다. 시트를 공개하지 않아도 되고,
   `TOKEN`을 넣으면 주소를 알아도 접근할 수 없습니다.
2. **엑셀(.xlsx)·CSV 불러오기** — 기기에 있는 파일을 브라우저에서 직접 읽습니다. 서버로 전송하지 않습니다.

앱을 처음 열면 **예시 핀 5개**만 보입니다. ⚙ 설정에서 실제 데이터를 불러오면 됩니다.

## 쓰는 법

1. 앱 열기 → 오른쪽 위 ⚙
2. **엑셀·CSV 불러오기 → 파일 선택** → `노원구_학원_영업DB.xlsx` 선택 (1,412곳)
   - 또는 **구글 시트 실시간 연동**: 안내대로 시트에 `apps-script-code.txt`를 붙여넣고 웹 앱을 배포한 뒤 URL을 입력
3. 끝. 지도에서 핀을 누르면 전화·문자·네이버지도·카카오맵·티맵으로 바로 연결됩니다.

## 기능

- **상태별 색깔 핀** — 미방문(파랑) · 명함전달(주황) · 관심(초록) · 재방문(보라) · 계약완료(남색) · 제외/거절(회색)
- **현위치(GPS)** — 현재 위치 기준 거리(m/km) 표시, 가까운 순 정렬
- **필터·검색** — 동별(중계·상계·공릉·월계·하계), 구분(학원/교습소), 영업상태, **원격·독서실 제외**,
  정렬(정원 큰 순·가까운 순·이름 순), 학원명·주소·과정·메모 통합 검색
- **상세 바텀시트** — 학원명·구분·동·정원·분야·주소, 전화 걸기 / 문자 / 내비 3종,
  영업상태 원터치 변경, 전화번호·방문메모 수정 저장
- **+ 새 영업처 추가** — 현위치 또는 지도에서 위치를 찍어 추가 (시트 연동 시 시트에 행 추가)
- **CSV 내보내기** — 지금 화면의 목록을 파일로 백업
- **오프라인** — 앱 껍데기와 최근 지도 타일은 캐시되어, 전파가 약해도 열립니다.

## 데이터 열 (시트·엑셀 공통)

`번호` | `학원명` | `구분` | `동` | `주소` | `우편번호` | `전화번호` | `분야` | `교습계열` | `교습과정` |
`정원` | `개설일자` | `학원지정번호` | `영업상태` | `방문메모` | `위도` | `경도`

머리글 이름으로 열을 찾으므로 순서가 달라도 됩니다(`학원명` 열은 필수).

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` · `styles.css` · `app.js` | 앱 본체 (외부 라이브러리 없이 Leaflet CDN만 사용) |
| `apps-script-code.txt` | 구글 시트 연동용 Apps Script `Code.gs` 전문 (복사해서 붙여넣기) |
| `manifest.webmanifest` · `sw.js` | PWA 설치·오프라인 |
| `icons/` | 홈 화면 아이콘 |

## 배포 메모

- 파일을 고쳐 올릴 때는 `sw.js`의 `VERSION`/`BUILD`를 올려야 폰에서 새 버전이 보입니다.
- 상위 대시보드(`/haemil-dashboard/`)의 서비스 워커도 이 폴더를 지나가므로, 큰 수정 뒤에는
  상위 `sw.js`의 `BUILD`도 함께 올립니다.
