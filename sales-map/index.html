구글 시트 실시간 연동

미연동

영업상태·메모·전화번호를 바꾸면 시트 해당 행에 바로 저장됩니다. 시트를 공개하지 않아도 되고, 주소를 아는 사람은 접근 토큰으로 막습니다.

대상 시트 [영업DB] 노원구 학원 목록 · 학원목록 ↗
  1. 시트에서 확장 프로그램 → Apps Script를 엽니다.
  2. 아래 Code.gs 복사를 눌러 코드를 통째로 붙여넣고 저장(Ctrl+S)합니다.
  3. 배포 → 새 배포 → 유형: 웹 앱 · 실행: 나 · 액세스: 모든 사용자 → 배포합니다.
  4. 나온 웹 앱 URL을 아래에 붙여넣고 저장하고 연결을 누릅니다.

기기 저장 데이터

학원 명단과 방문 기록은 이 기기 브라우저(localStorage)에만 저장됩니다. 앱 파일(공개 저장소)에는 명단이 들어가지 않습니다. 브라우저 데이터를 지우면 함께 사라지니, 시트 연동이나 CSV 내보내기로 백업하세요.
