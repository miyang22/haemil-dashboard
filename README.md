# 해밀홈케어 · 매출·비용 관리 대시보드

에어컨 분해 세척 작업의 **기종별 대수만 입력하면 매출이 자동 계산**되는 1인 사업장용 장부 앱입니다.
휴대폰에서 쓰기 편하도록 모바일 우선으로 만들었고, PC에서는 더 넓은 화면으로 정리해 볼 수 있습니다.

## 파일

```
sites/haemil-dashboard/
├── index.html            화면 구조
├── styles.css            디자인·반응형(모바일 390px ~ 데스크톱 1280px)
├── app.js                계산·저장·차트·내보내기 (외부 라이브러리 없음)
├── manifest.webmanifest  홈 화면 설치(PWA) 매니페스트
├── sw.js                 오프라인 캐시 서비스 워커
├── icons/
│   ├── icon-192.png      앱 아이콘 192×192
│   └── icon-512.png      앱 아이콘 512×512
├── preview-mobile.png / preview-desktop.png / preview-icon.png   미리보기
└── README.md
```

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 동작하고, 폴더째 어떤 정적 호스팅
(GitHub Pages, Vercel, Netlify, 일반 웹호스팅)에 올려도 그대로 실행됩니다.
외부 CDN·폰트·이미지 의존성이 없어 인터넷 없이도 열립니다.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| **요약** | 월간·분기·반기·연간 요약. 총 매출 / 총 비용 / 순이익 / 작업 대수·마진율, 매출·비용 추이 차트, 기종별 대수(도넛), 비용 구성, 기간 내 기록 목록(수정·삭제) |
| **매출 입력** | 날짜 + 기종별 대수(스테퍼 또는 직접 입력) → 합계 자동 계산. 기타 추가 매출, 조정 금액(할인은 `-`), 현장 메모 |
| **비용** | 날짜·분류·금액·메모로 비용 기록, 최근 비용 수정·삭제. 분류 옆 **+ 항목 추가** 로 그 자리에서 새 분류를 만들 수 있습니다 |
| **관리** | 기종 이름·단가 수정, 기종 추가/숨김, 비용 분류 관리, 자주 쓰는 메모, CSV·JSON 내보내기/불러오기, 예시 데이터 지우기 |

기간은 `‹ ›` 로 이동하고 **오늘** 버튼으로 이번 기간으로 돌아옵니다.

## 처음 시작할 때

처음 열면 화면을 바로 확인할 수 있도록 **예시 기록과 예시 단가**가 들어 있습니다.
상단 노란 안내의 **예시 데이터 지우기**를 누르면 샘플 기록만 지워지고(단가·분류 설정은 유지),
**관리 → 기종별 단가**에서 실제 단가를 넣으면 됩니다.

> 예시 단가(벽걸이 110,000원 등)는 실제 시세가 아니라 화면 확인용 임의 값입니다.
> 반드시 관리 탭에서 해밀홈케어의 실제 단가로 바꿔 주세요. 단가를 바꾸면 과거 기록 금액도
> 새 단가로 다시 계산됩니다(기록은 "대수"만 저장하기 때문입니다).

## 데이터 저장

- 모든 기록과 설정은 **이 브라우저의 localStorage** 에 자동 저장됩니다. 서버로 전송되지 않습니다.
- 그래서 **기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다.**
  관리 탭의 **JSON 백업**을 주기적으로 받아 두고, 새 기기에서 **JSON 불러오기**로 복원하세요.
- 휴대폰 브라우저에서 "홈 화면에 추가"로 열면 앱처럼 쓸 수 있습니다.

## 홈 화면에 설치하기 (PWA)

이 앱은 **설치형 웹앱(PWA)** 입니다. 주소만 열어 두는 것보다 홈 화면에 설치하면 앱처럼 바로 열립니다.
설치하면 주소창·브라우저 메뉴가 없는 전체 화면으로 뜨고, **인터넷이 끊겨도 화면이 열립니다.**

- **안드로이드(Chrome)**: 주소창 오른쪽 `⋮` → **앱 설치** / **홈 화면에 추가**
- **아이폰(Safari)**: 아래 **공유** 버튼 → **홈 화면에 추가**
- **PC(Chrome·Edge)**: 주소창 오른쪽 설치 아이콘(모니터에 ↓ 표시) 클릭

설치는 `https://` 주소에서만 동작합니다(GitHub Pages·Vercel·Netlify 등은 자동으로 https).

### 오프라인 동작 방식

`sw.js` 서비스 워커가 `index.html`·`styles.css`·`app.js`·매니페스트·아이콘을 기기에 캐시해 두고,
인터넷이 없으면 이 캐시로 화면을 엽니다. 기록 데이터는 원래부터 기기(localStorage)에만 있으므로
**비행기 모드·지하에서도 조회와 입력이 그대로 됩니다.**
바뀐 파일을 다시 배포할 때는 `sw.js` 의 `VERSION` 값(`v1` → `v2`)을 올려 주세요.
그러면 다음 방문 때 새 캐시로 교체됩니다.

### GitHub Pages 에 올리기

모든 경로가 상대 경로(`./`)라서 **저장소 루트(`/`)와 하위 경로(`/<저장소>/`) 어디에 올려도** 그대로 동작합니다.
`sites/haemil-dashboard/` 안의 파일 전체를 저장소에 올리고 Settings → Pages 에서 지정하면 끝입니다.

## 내보내기

- **CSV**: 엑셀에서 바로 열리도록 UTF-8 BOM으로 저장합니다(한글 깨짐 없음).
  `[매출]` 시트에는 기종별 대수·금액·기타·조정·합계, `[비용]` 에는 날짜·분류·금액·메모,
  끝에 `[요약]`(총매출·총비용·순이익·대수·마진율)이 붙습니다.
  "지금 보고 있는 기간"과 "전체 기간" 두 가지로 내보낼 수 있습니다.
- **JSON**: 기록 전체를 파일 하나로 백업/복원합니다.

## 단가·분류 바꾸기

관리 탭에서 바로 고치면 즉시 저장됩니다.

- 기종: 이름, 단가, **사용** 체크(입력 화면에 보일지), 삭제
- 이미 기록에 쓰인 기종은 삭제되지 않습니다. 대신 **사용** 체크를 끄면 입력 화면에서만 숨겨집니다.
- 비용 분류를 지워도 그 분류로 기록한 비용은 이름을 그대로 유지합니다.
- **비용 탭에서도 분류를 바로 추가**할 수 있습니다. 분류 선택칸 오른쪽 **+ 항목 추가** 를 누르고 이름을 넣으면,
  저장과 동시에 그 분류가 선택되고 관리 탭 목록에도 함께 나타납니다(이미 있는 이름이면 새로 만들지 않고 그것을 선택).
- 기본 비용 분류는 약품·자재비 / 유류·주차·통행비 / 광고·마케팅비 / 식대·기타경비 / 장비유지비 / **커피** / **담배** 입니다.
  이전 버전을 쓰던 기기는 앱을 열 때 ‘커피’·‘담배’ 가 목록 끝에 한 번만 더해지고, 나중에 직접 지운 분류는 다시 생기지 않습니다.

## 계산 방식

```
매출(건) = Σ(기종별 대수 × 그 기종 단가) + 기타 추가 매출 + 조정 금액
순이익   = 기간 매출 합계 − 기간 비용 합계
마진율   = 순이익 ÷ 매출 × 100
```

분기 = 1~3 / 4~6 / 7~9 / 10~12월, 반기 = 1~6 / 7~12월입니다.

## 확인한 것

실제 headless Chromium(Playwright)으로 모바일 390px·데스크톱 1280px 두 화면을 검증했습니다.

- 전 탭 가로 스크롤(오버플로) 없음, JS/콘솔 에러 없음
- 대수 입력 → 자동 합계, 저장 후 KPI 반영, 비용 추가 반영
- 관리에서 단가 변경 시 전체 매출 재계산(벽걸이 110,000→120,000원, 97대 → +970,000원)
- 월간/분기/반기/연간 전환과 기간 이동, 연간 합계 = 원장 직접 합계
- 새로고침 후 localStorage 유지, CSV·JSON 다운로드 동작, 기록 삭제 동작
- (v2) 기본 분류에 **커피·담배** 추가, 분류 옆 **+ 항목 추가** 로 비용 탭에서 즉시 분류 생성 → 바로 선택·관리 탭 동기화
- (v2) 구버전 저장 데이터(5개 분류 + 직접 만든 분류) 마이그레이션: 기록·금액 그대로, 커피·담배만 끝에 추가, 삭제한 분류는 재생성 안 됨

### PWA(설치·오프라인) 검증

실제 headless Chromium 으로 **루트(`/index.html`)** 와 **하위 경로(`/haemil-dashboard/index.html`)** 두 환경에서
HTTP 로 서빙해 90개 항목을 확인했고 전부 통과했습니다.

- `manifest.webmanifest`·`sw.js`·`icon-192.png`·`icon-512.png` 모두 200, 매니페스트 JSON 파싱 오류 없음
- Chrome 설치 가능성 검사(`Page.getInstallabilityErrors`) 오류 0건
- 서비스 워커 등록 → `activated` 상태, 스코프가 앱 경로로 정확히 잡힘(`/` 와 `/haemil-dashboard/` 모두)
- 캐시에 `./`·`index.html`·`styles.css`·`app.js`·매니페스트·아이콘 2종 저장 확인
- **오프라인 모드로 전환 후 새로고침해도 앱·CSS 정상 로딩**(KPI 4개 렌더)
- 4개 탭 전환·가로 오버플로 없음, 콘솔 에러·페이지 에러·실패한 요청 0건
- `start_url`(폴더 URL) 로 바로 열어도 앱 로딩
