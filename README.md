# 해밀홈케어 · 매출·비용·통화예약 관리 대시보드

에어컨 분해 세척 작업의 **기종별 대수만 입력하면 매출이 자동 계산**되는 1인 사업장용 장부 앱입니다.
전화로 받은 **통화예약**을 구글시트(`통화예약 정리`)와 양방향으로 맞추는 탭이 함께 들어 있습니다.
휴대폰에서 쓰기 편하도록 모바일 우선으로 만들었고, PC에서는 더 넓은 화면으로 정리해 볼 수 있습니다.

## 파일

```
sites/haemil-dashboard/
├── index.html            화면 구조
├── styles.css            디자인·반응형(모바일 390px ~ 데스크톱 1280px)
├── app.js                계산·저장·차트·내보내기·통화예약·시트 연동 (외부 라이브러리 없음)
├── manifest.webmanifest  홈 화면 설치(PWA) 매니페스트
├── sw.js                 오프라인 캐시 서비스 워커
├── icons/
│   ├── icon-192.png      앱 아이콘 192×192
│   └── icon-512.png      앱 아이콘 512×512
├── preview-mobile.png / preview-desktop.png / preview-icon.png   미리보기
└── README.md
```

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 동작하고, 폴더째 어떤 정적 호스팅
(GitHub Pages, Vercel, Netlify, 일반 웹호스팅)에 올려도 그대로 실행됩니다.
외부 CDN·폰트·이미지 의존성이 없어 인터넷 없이도 열립니다.

| **통화예약** | 전화로 받은 예약 목록. 전체·미완료·예정 요약, 전체/미완료/예정/완료 필터, 통합 검색, 카드에서 **완료 한 번에 토글**, 새 예약·수정·삭제, 예시 2건. 구글시트 `통화예약 정리`(탭 `시트1`)와 양방향 연동 |

| **비용** | 날짜·분류·금액·메모로 비용 기록, 최근 비용 수정·삭제. 분류 옆 **+ 항목 추가** 로 그 자리에서 새 분류를 만들 수 있습니다 |

| **관리** | 기종 이름·단가 수정, 기종 추가/숨김, 비용 분류 관리, 자주 쓰는 메모, CSV·JSON 내보내기/불러오기, 예시 데이터 지우기 |

기간은 `‹ ›` 로 이동하고 **오늘** 버튼으로 이번 기간으로 돌아옵니다.

### 현장별 매출

요약 탭의 **현장별 매출** 카드는 그 기간 매출 기록을 **현장 메모(`메모` 칸)별로 묶어** 금액이 큰 순서대로 보여 줍니다.

- 각 줄: 현장 이름 · `3대 · 22%`(작업 대수·매출 비중) · 금액 · 가로 막대
- 현장 메모를 비워 둔 기록은 **미지정(현장 미입력)** 으로 따로 묶입니다.
- 10곳이 넘으면 앞 10곳만 보여 주고, 나머지는 **그 외 N곳** 한 줄로 합쳐서 보여 줍니다.
- 월간·분기·반기·연간 어느 기간에서든, 단가나 기록을 고치면 합계와 막대가 바로 다시 계산됩니다.

## 통화예약

전화로 받은 예약을 그 자리에서 적고, 끝나면 한 번 눌러 완료 처리하는 탭입니다.
구글시트 `통화예약 정리`(탭 `시트1`)와 연결하면 폰과 시트가 양방향으로 맞춰집니다.

### 화면

- **위쪽 요약**: 전체 · 미완료 · 예정. **예정**은 미완료 중 예약일이 아직 남은 건수입니다(오늘 포함).
  세 칸을 누르면 그 목록으로 바로 걸러집니다.
- **필터**: 전체 / 미완료 / 예정 / 완료. **검색**은 이름·주소·청소수량·메모·예약일을 한 번에 찾습니다.
- **카드**: 고객명, 예약일(`11월 28일 (토) 10:00`), `D-2`·`오늘`·`3일 지남` 표시, 주소, 청소수량, 기타 메모.
  - 왼쪽 **동그라미를 한 번 누르면 완료**, 다시 누르면 미완료로 돌아갑니다(연동 중이면 시트에도 바로 반영).
  - **수정**은 고객명·예약일·시간·주소·청소수량·기타 메모를 모두 고칠 수 있고, **삭제**는 확인을 한 번 받습니다.
- **정렬**: 미완료는 예약일이 가까운 순, 완료는 최근 것부터 아래에 모입니다. 예약일이 없는 건은 맨 뒤로 갑니다.
- **+ 새 예약**: 고객명만 넣고 저장해도 됩니다. 날짜는 **오늘/내일** 버튼으로 바로 채울 수 있습니다.
- 아래쪽 하단 메뉴의 **통화예약**에는 아직 안 지난 미완료 예약 수가 주황색 숫자로 표시됩니다.

예약은 다른 기록과 같이 **이 기기의 localStorage**에 저장되므로, 연동을 하지 않아도 그대로 쓸 수 있습니다.
처음 열면 화면을 확인할 수 있도록 **예시 예약 2건**이 들어 있고, 위쪽 안내의 **예시 예약 지우기**로 한 번에 지웁니다
(관리 탭의 **예시 데이터 지우기**로도 함께 지워집니다).

### 구글시트 연동 (2분)

앱과 시트가 **같은 구글 계정**일 필요는 없습니다. 시트를 열 수 있는 계정이면 됩니다.

1. **통화예약 → 연동 설정 → 시트 열기** 로 `통화예약 정리` 시트를 엽니다.
2. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다.
3. **Code.gs 복사** 버튼으로 받은 코드를 코드 창에 통째로 붙여넣고 저장합니다(Ctrl+S).
   원래 있던 `function myFunction() {}` 은 지우면 됩니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** 를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 앱의 **웹 앱 URL** 칸에 붙여넣고 **저장하고 연결** 을 누릅니다. 바로 시트와 맞춰 보고 결과를 알려 줍니다.

이후에는 예약을 추가·수정·완료·삭제할 때마다 시트로 보내고, 앱을 열 때·통화예약 탭을 열 때 시트 내용을 받아옵니다.
**지금 동기화** 버튼으로 언제든 직접 맞출 수 있습니다.

#### 동기화 규칙

- 시트의 **행 번호**로 같은 예약을 알아봅니다. 앱에서 고친 내용(`시트 전송 대기` 표시)이 있으면 앱이 우선이고,
  그 밖에는 시트가 기준입니다. **시트에서 직접 고치거나 지운 내용도 다음 동기화 때 화면에 반영**됩니다.
- 앱에서 삭제하면 시트에서도 그 행을 지웁니다. 이때 **고객명이 다르면 지우지 않고 멈춥니다**(행이 밀린 경우 보호).
- 시트가 **통째로 비어 있으면** 실수로 지운 것으로 보고, 앱의 예약을 시트로 다시 올립니다.
- **예시 예약은 시트로 올라가지 않습니다.** 연동을 처음 걸면 그때까지 앱에 있던 실제 예약이 시트로 올라갑니다.
- 시트에 들어가는 값: 고객명 / 주소 / 청소수량 / **예약확정 일 및 시간**(`2026-11-28 10:00` 글자) /
  **완료여부**(`완료` 또는 `미완료`) / 기타.
- 시트에 `O`, `TRUE`, `완료` 처럼 적어도 완료로 읽고, 날짜는 `2026-11-28 10:00` · `11/28 10:00` · `11월 28일 10시` 모두 읽습니다.

#### 알아 둘 것

- 웹 앱 URL을 아는 사람은 예약 내용을 읽을 수 있습니다. 주소를 남에게 보내지 마세요.
  신경이 쓰이면 코드의 `var TOKEN = '';` 에 글자를 넣고 앱의 **접근 토큰**에 같은 글자를 적으면, 주소만으로는 열리지 않습니다.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다(새 배포를 또 만들면 URL이 바뀝니다).
- 연동 상태는 통화예약 탭 위쪽 막대에 나옵니다. 문제가 있으면 줄에 이유가 표시되고, 마지막 동기화 시각도 함께 보입니다.
- 연동을 끊어도(**연결 해제**) 화면의 예약은 그대로 남습니다.

## 처음 시작할 때

처음 열면 화면을 바로 확인할 수 있도록 **예시 기록과 예시 단가**가 들어 있습니다.
상단 노란 안내의 **예시 데이터 지우기**를 누르면 샘플 기록만 지워지고(단가·분류 설정은 유지),
**관리 → 기종별 단가**에서 실제 단가를 넣으면 됩니다.

> 예시 단가(벽걸이 110,000원 등)는 실제 시세가 아니라 화면 확인용 임의 값입니다.
> 반드시 관리 탭에서 해밀홈케어의 실제 단가로 바꿔 주세요. 단가를 바꾸면 과거 기록 금액도
> 새 단가로 다시 계산됩니다(기록은 "대수"만 저장하기 때문입니다).

## 견적서

**견적서** 탭에서 보내 주신 견적서와 같은 A4 견적서를 바로 만들 수 있습니다.

1. **문서 정보**: 작성일(화면에 `2026년 11월 24일` 형식으로 표시), 견적번호(`2026-001` 자동 생성, 직접 수정 가능),
   수신(기관·담당자), 수신 이메일, 참조, 유효기간(기본 `작성일로부터 1주일간`)
2. **공급자 정보**: 상호 `해밀홈케어` · 성명 `문병철` · TEL `1600-1970` 이 기본으로 들어 있습니다.
   등록번호·주소·E-mail·계좌정보는 **직접 한 번만 입력해 두면 이 기기에 저장**되어 다음 견적서부터 자동으로 채워집니다.
   (사업자번호·주소·메일 같은 개인 정보는 공개 저장소 소스에 넣지 않고, 브라우저 localStorage 에만 저장합니다.)
3. **품목**: 관리 탭의 기종을 누르면 품목·단가가 바로 들어가고(다시 누르면 수량 +1), **+ 품목 줄 추가** 로 직접 적을 수도 있습니다.
   각 줄의 규격/사양(기본 `기본`), 단위(기본 `EA`), 수량, 단가를 고치면 공급가액·세액이 바로 계산됩니다.
   단가는 견적서마다 다르게 고칠 수 있습니다(관리 탭의 기본 단가는 그대로 유지).
4. **부가세 10% 포함** 스위치를 끄면 세액이 0원이 되고 합계금액이 공급가액과 같아집니다.
5. **합계금액**은 숫자와 함께 `일금 일백육십칠만이천 원정` 처럼 한글로도 표시됩니다.
6. **비고**에는 표준 문구(친환경 세척 개요 / 세척 후 사후관리 / 결제방법)가 들어 있고 자유롭게 고칠 수 있습니다.
   고친 문구는 저장되어 다음 견적서에 그대로 쓰입니다(기본 문구로 되돌리기 버튼 있음).

### 인쇄 · PDF · 이미지

- **PDF 저장 · 인쇄**: 앱 화면은 숨어지고 **A4 견적서 한 장만** 인쇄됩니다(인쇄 대화상자에서 ‘PDF로 저장’ 선택).
- **이미지 저장(PNG)**: 카카오톡·문자로 바로 보낼 수 있도록 견적서를 고해상도 PNG(약 152dpi, 1260×1782)로 저장합니다.
  외부 라이브러리 없이 캔버스로 직접 그리기 때문에 인터넷이 없어도 됩니다.
- **크게 보기**: 미리보기 머리말의 버튼을 누르면 같은 견적서가 새 탭에 원본 크기로 열려, 폰에서도 손가락으로 확대해 확인할 수 있습니다.

### 이메일 발송

견적서 탭 아래 **이메일 발송** 버턴 하나로 보냅니다.

- **설정 없이 바로**: 수신 이메일과 내 메일(설정 영역)을 넣고 누르면,
  **받는 사람 = 상대방, 참조 = 내 메일** 로 제목·본문(품목·수량·단가·합계·비고·계좌)이 채워진 메일 앱이 열립니다.
- **EmailJS 연결 시(1클릭 자동발송)**: 서비스 ID·템플릿 ID·Public Key 를 넣고 저장하면,
  앱에서 **상대방 메일과 내 메일로 동시에** 발송합니다(2회 발송, 서로 참조).
  템플릿 받는 사람은 `{{to_email}}`, 참조는 `{{cc_email}}`, 본문은 `{{message}}`,
  그 밖에 `{{subject}}` `{{quote_no}}` `{{quote_date}}` `{{receiver}}` `{{total}}` `{{total_krw}}` `{{items_summary}}` `{{account}}` `{{from_name}}` `{{reply_to}}` 를 쓸 수 있습니다.
- EmailJS 설정값도 이 기기의 localStorage 에만 저장됩니다.

### 작성 중인 견적서

작성하다 앱을 닫아도 **마지막으로 쓰던 견적서가 기기에 임시 저장**되어, 다시 열면 이어서 쓸 수 있습니다.
**새 견적**을 누르면 초안이 비워집니다.

### 발행 내역

저장한 견적서는 **발행 내역**에 쌓입니다. **불러오기**로 다시 열어 고치거나 다시 인쇄하고,
**복제**로 새 번호의 견적서를 만들고, **이 내역으로 매출 등록**을 누르면 품목·금액이 매출 입력 탭으로 옮겨집니다
(이름이 같은 기종은 대수로, 나머지는 기타 매출로 들어가고, 합계가 견적 금액과 같아지도록 조정됩니다).

## 데이터 저장

- 모든 기록과 설정은 **이 브라우저의 localStorage** 에 자동 저장됩니다. 서버로 전송되지 않습니다.
  (통화예약도 같은 곳에 저장되고, 구글시트 연동을 켰을 때만 예약 내용이 그 시트로 전송됩니다.)
- 그래서 **기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다.**
  관리 탭의 **JSON 백업**을 주기적으로 받아 두고, 새 기기에서 **JSON 불러오기**로 복원하세요.
- 휴대폰 브라우저에서 "홈 화면에 추가"로 열면 앱처럼 쓸 수 있습니다.

## 홈 화면에 설치하기 (PWA)

이 앱은 **설치형 웹앱(PWA)** 입니다. 주소만 열어 두는 것보다 홈 화면에 설치하면 앱처럼 바로 열립니다.
설치하면 주소창·브라우저 메뉴가 없는 전체 화면으로 뜨고, **인터넷이 끊겨도 화면이 열립니다.**

- **안드로이드(Chrome)**: 주소창 오른쪽 `⋮` → **앱 설치** / **홈 화면에 추가**
- **아이폰(Safari)**: 아래 **공유** 버튼 → **홈 화면에 추가**
- **PC(Chrome·Edge)**: 주소창 오른쪽 설치 아이콘(모니터에 ↓ 표시) 클릭

설치는 `https://` 주소에서만 동작합니다(GitHub Pages·Vercel·Netlify 등은 자동으로 https).

### 오프라인 동작 방식

`sw.js` 서비스 워커가 `index.html`·`styles.css`·`app.js`·매니페스트·아이콘을 기기에 캐시해 두고,
인터넷이 없으면 이 캐시로 화면을 엽니다. 기록 데이터는 원래부터 기기(localStorage)에만 있으므로
**비행기 모드·지하에서도 조회와 입력이 그대로 됩니다.**
바뀐 파일을 다시 배포할 때는 `sw.js` 의 `VERSION` 값(`v1` → `v2` → `v3` → `v4`)을 올려 주세요.
그러면 다음 방문 때 새 캐시로 교체됩니다.

### GitHub Pages 에 올리기

모든 경로가 상대 경로(`./`)라서 **저장소 루트(`/`)와 하위 경로(`/<저장소>/`) 어디에 올려도** 그대로 동작합니다.
`sites/haemil-dashboard/` 안의 파일 전체를 저장소에 올리고 Settings → Pages 에서 지정하면 끝입니다.

## 내보내기

- **CSV**: 엑셀에서 바로 열리도록 UTF-8 BOM으로 저장합니다(한글 깨짐 없음).
  `[매출]` 시트에는 기종별 대수·금액·기타·조정·합계, `[비용]` 에는 날짜·분류·금액·메모,
  끝에 `[요약]`(총매출·총비용·순이익·대수·마진율)이 붙습니다.
  "지금 보고 있는 기간"과 "전체 기간" 두 가지로 내보낼 수 있습니다.
- **JSON**: 기록 전체를 파일 하나로 백업/복원합니다(통화예약·시트 연동 설정 포함).
- 통화예약은 CSV에는 들어가지 않습니다. 예약을 표로 백업하려면 JSON 백업을 받아 두세요.

## 단가·분류 바꾸기

관리 탭에서 바로 고치면 즉시 저장됩니다.

- 기종: 이름, 단가, **사용** 체크(입력 화면에 보일지), 삭제
- 이미 기록에 쓰인 기종은 삭제되지 않습니다. 대신 **사용** 체크를 끄면 입력 화면에서만 숨겨집니다.
- 비용 분류를 지워도 그 분류로 기록한 비용은 이름을 그대로 유지합니다.
- **비용 탭에서도 분류를 바로 추가**할 수 있습니다. 분류 선택칸 오른쪽 **+ 항목 추가** 를 누르고 이름을 넣으면,
  저장과 동시에 그 분류가 선택되고 관리 탭 목록에도 함께 나타납니다(이미 있는 이름이면 새로 만들지 않고 그것을 선택).
- 기본 비용 분류는 약품·자재비 / 유류·주차·통행비 / 광고·마케팅비 / 식대·기타경비 / 장비유지비 / **커피** / **담배** 입니다.
  이전 버전을 쓰던 기기는 앱을 열 때 ‘커피’·‘담배’ 가 목록 끝에 한 번만 더해지고, 나중에 직접 지운 분류는 다시 생기지 않습니다.

## 계산 방식

```
매출(건) = Σ(기종별 대수 × 그 기종 단가) + 기타 추가 매출 + 조정 금액
순이익   = 기간 매출 합계 − 기간 비용 합계
마진율   = 순이익 ÷ 매출 × 100
```

분기 = 1~3 / 4~6 / 7~9 / 10~12월, 반기 = 1~6 / 7~12월입니다.
